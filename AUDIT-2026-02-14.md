### 4. Security Engineer — 6/10 ⚠️ FLAG

**Issue #3: ZIP Slip Vulnerability (Potential)**

**Location:** `writers/import_zip_to_student_groups.py`
```python
with zipfile.ZipFile(zip_path, "r") as z:
    z.extractall(temp_extract)  # No path validation!
```

**Risk:** A malicious ZIP could contain files with paths like `../../etc/passwd` that escape the target directory.

**Python Version:** 3.9.6 — `extractall()` is NOT safe against path traversal in this version (fixed in 3.11.4+).

**Likelihood:** LOW — students submit ZIPs, unlikely to be malicious
**Impact:** HIGH — arbitrary file write if exploited

**Mitigation Options:**
1. Upgrade to Python 3.11.4+ (extractall fixed)
2. Add manual path validation before extraction
3. Use `zipfile.Path` with validation

**Other Security Notes:**
- ✅ Files processed locally (no network exposure)
- ✅ No credentials stored
- ✅ CORS allows all (acceptable for local desktop app)
